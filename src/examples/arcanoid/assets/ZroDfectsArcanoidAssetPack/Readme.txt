Zro Dfects – Arkanoid Bat 'N Ball Breakout Style Tileset (Complete Pack)

A huge thank you for downloading my pixel tile asset pack — I really appreciate your interest and support, it really means a lot and highly appreciated.

🎨 What’s Included:
- Screen/canvas size is 640x360, perfect for when zooming on HD ready screens, canvas size can be changed to suit your style.
- 16x16 tile sets (some sprites will be 16x8, 16x32 or 16x48 tiled, but are all separate at 16x16.
- 10 various themed/styled bats to suit your theme or style
- All 10 bats have 3 sizes of tiny/shrunk, default/standard and fully extended, each with an additional in between frame for stretching or shrinking when using bonus drop down.
- All 10 bats also have additional tiles sets with red and blue animated lights In all sizes if you wish to use them for shooting bullets feature for example.
- All 10 bats also have a micro bat version to use as a player life/bat counter (for example use 3 for 3 lives etc)
- 6 various colored balls to choose, for example red for main, and use all for an animated rainbow bonus that smashes through all blocks in it's path. there are 6 small standard balls plus 6 larger sets for any bonus use (total 12).
- 1 set of bullets to use for a bonus feature
- 15 various colored smashable blocks, in two styles (30 in total) plenty of colors to create pixel art or pattern style block layouts.
- 8 various colored play area background tiles that join seamlessly.
- 8 various colored UI background area tiles that join seamlessly.
- 3 various colored borders to use around the play area, each have inner color sections due to the shape which can blend in with your out of 8 chosen colored background tile, total 24 colored combinations.
- 3 various colored borders to use around the UI section.
- 8 various colored bonus drop items with 6 rotating animated frames for each
- 2 different colored unbreakable blocks with 6 hit reflection animated frames
- A-Z and 0-9 text with the additional "#" and "!", to use in game
- 1 mock up of a gameplay example you are free to use (plus a complete tiled version for easy cut and paste) 640x360
- 3 block layout designs you may also use if you wish 640x360.
- All the tile sets have transparent backgrounds and each tile set is labelled as per deign use, but you can use them in your own way as you wish.
- There is an optional display window section as part of the UI to show your games title name or a logo, or anything else you wish, just keep in mind that you may not be able to sell your game using the Arkanoid title name, so I would recommend creating your own breakout game title name.

📌 Notes:
- Over time there may be additional levels added to help give users a head start with layout designs if needed.
- There are 5 frames per bat extension and labelled accordingly --> tiny (playable as a bonus), shrinking (used as a animated bat between tiny and default), default standard playable and used to start the game with, enlarging (used as an animated bat between standard and stretched), extended (playable as a bonus).
- If you use a bonus where the bat shrinks from extended to tiny or tiny to extended, you can use all the frames to work in this way.
